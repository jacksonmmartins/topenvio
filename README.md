# topenvio 🚀

**topenvio** é uma plataforma de serviço de entregas de mercadorias, que abrange todo o país. De entregas de A a Z. Focado na segurança de seus dados, e bem estar do cliente. 

Deploy realizado na Vercel, disponível no endereço: 

https://topenvio.vercel.app/
---

## 🧩 Tecnologias & Ferramentas Principais

Aqui vão as principais tecnologias usadas no projeto:

| Camada / Finalidade | Tecnologia / Ferramenta |
|---------------------|---------------------------|
| Front-end | JavaScript, CSS, HTML, React, Vue.js
| Build / Bundler | Vite |
| Back-end | Node.js / Express 
| Comunicação | API REST (JSON) |
| Hospedagem / Deploy | Vercel |
| Gerenciamento de pacotes | npm 
| Estrutura de pastas | Separação entre **Front End** e **Back End** |
| Boas práticas | Modularização, separação de responsabilidades, padrões de código, documentação de rotas, variáveis de ambiente |
---

## 🚀 Instalação e Execução

Siga estas etapas para rodar o projeto localmente:

```bash
# Clone o repositório
git clone https://github.com/jacksonmmartins/topenvio.git

# Acesse o diretório
cd topenvio

# Dependências front-end
cd Front\ End
npm install
npm run dev

# Dependências back-end
cd ../Back\ End
npm install
npm run dev
